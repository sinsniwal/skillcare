# cleanse

## Target
Boilerplate, UI elements, navigation menus, ads, layout artifacts, and raw structural markup.

## Goal
Leave only the core readable content (body text, intrinsic headings, data tables).

## Rules
1. Do not summarize. 
2. Preserve the substantive text exactly; only remove the surrounding noise.
3. If the text is already clean, return it unchanged.
