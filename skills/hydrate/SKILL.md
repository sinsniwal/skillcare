# hydrate

## Target
Unexplained acronyms, domain-specific jargon, vague references, and assumed background knowledge.

## Goal
A fully contextualized text where terms are defined inline (on first use) so no external knowledge is required to understand it.

## Rules
1. Do not alter the original facts.
2. Keep additions concise (e.g., a short parenthetical or footnote).
3. If unsure about an expansion, mark it for clarification.
