# exfoliate

## Target
Marketing hype, emotional hooks, subjective adjectives, author editorializing, and unsupported persuasive copy.

## Goal
A skeletal representation of verifiable facts, metrics, and objective data points.

## Rules
1. Only subtract, never add.
2. If a statement is borderline opinion, cut it.
3. If a surviving claim lacks a clear source, flag it with `[uncited]`.
