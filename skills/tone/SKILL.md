# tone

## Target
Broken hierarchies, inconsistent list markers, garbled encoding, malformed tables, and messy whitespace.

## Goal
A perfectly structured, standardized, and easily parsable output. 

## Rules
1. Change only the presentation, never the underlying meaning.
2. If a table or structure is mangled beyond repair, convert it to a simpler format (like a definition list).
